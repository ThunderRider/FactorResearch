## 3. 交易结构

| 项目 | 规则 |
|---|---|
| 建仓 | T 日 14:45（尾盘） |
| 平仓 | T+1 日 11:15（默认）或 13:30（需计滑点） |
| 持仓周期 | 约 20.5 / 22.75 小时 |
| 换手 | 每日 100% 全换 |
| 持仓数 | 8 只（两个池各 4 只） |
| 单票上限 | 19% |
| 总预算 | 96% |

**收益三段分解**（V6 起沿用，用于归因）：

| 段 | 区间 | 含义 |
|---|---|---|
| `ret_tail` | 14:45 → 15:00 | 当日尾盘 |
| `ret_overnight` | 15:00 → 次日 9:30 | 隔夜跳空 |
| `ret_morning` | 9:30 → 11:15 | 次日早盘 |

> 为什么必须拆？因子对"隔夜"和"早盘"的预测力完全不同。若某因子只在隔夜段有 IC，
> 说明它赚的是隔夜溢价，改进方向应是尾盘资金意图，而不是继续调窗口。

## 5. 选股模型：三个因子

```python
score = −z(vol_ratio) + z(amihud[T−1]) − z(ret_20d)      # 池内 z-score，截尾 ±3
picks = 每池 score 前 4
```

### 5.1 `vol_ratio` —— 同时刻量比（缩量）

```
v1430     = 当日 14:00–14:30 的成交量
v_ma20    = 过去 20 个交易日"同一时点"的量均值（min_periods=10）
vol_ratio = v1430 / v_ma20
```

* **方向**：越小越好（取负号）。
* **逻辑**：A 股成交量有强烈的 U 型日内季节性；用同一时点做分母天然消掉季节性。
  "今天没人关注"的票，次日更容易被资金重新发现。
* **实测**：小盘池 IC −0.048（NW t = **−11.4**），是三因子里最强的。
* **V7 复核**：对 log 成交额 + 波动率正交后 **IC 保留 96%、净年化只掉 0.55pp** ——
  它是三因子中**唯一真正独立**的。

### 5.2 `amihud[T−1]` —— 非流动性（冷门）

```
daily_ret  = c1500 / c1500.shift(1) − 1
amihud_t   = |daily_ret| / day_amt
amihud     = rolling_mean(amihud_t, 20).shift(1)      # ← 滞后一天
```

* **方向**：越大越好。
* **逻辑**：单位成交额能推动多少价格（Amihud, 2002）。
* **实测**：小盘池 IC +0.033（NW t = **+5.5**）。
* **V7 复核（重要）**：对 log 成交额 + 波动 + 反转正交后，**IC 翻转为 −0.005，净年化从 9.59% 掉到 0.52%**。
  换句话说：**它不是"非流动性溢价"，而是"低流动性 + 高波动 + 超跌"的合成暴露。**
  V7 仍然保留它（置换重要性显示删掉会掉 13pp），但**对外表述必须改写**。

### 5.3 `ret_20d` —— 20 日反转（超跌）

```
ret_20d = c1430 / c1430.shift(20) − 1
```

* **方向**：取负号（跌得多的买）。
* **逻辑**：A 股中短周期强反转（处置效应 + 过度反应）。
* **实测**：小盘池 IC −0.052（NW t = **−6.8**），但 **2026 年衰减到 −0.029（腰斩）**。

### 5.4 合成方式

* **等权，不做权重优化**。P1-5 的置换重要性给出 amihud(0.98) ≫ ret_20d(0.61) > vol_ratio(0.35)，
  但按这个排序去调权重，等于在样本内又优化一次——V7 明确拒绝。
* **z-score 而非百分位秩**：保留"离均值多远"的信息（实测 25.6% vs 15.9% 毛年化）。
* **截尾 ±3**：防止单个极端值主导（±2 会砍掉太多信息）。

### 5.5 三因子在不同窗口的 IC

| 因子 | 2023 | 2024 | 2025 | 2026 | 全样本 | NW t |
|---|---|---|---|---|---|---|
| `vol_ratio` | −0.052 | −0.056 | −0.048 | −0.036 | **−0.048** | −11.4 |
| `amihud` | +0.030 | +0.027 | +0.034 | +0.035 | **+0.033** | +5.5 |
| `ret_20d` | −0.049 | −0.051 | −0.072 | **−0.029** | **−0.052** | −6.8 |

> 三因子日度 IC 之间的相关性：`vol_ratio × ret_20d = 0.34`、`amihud × ret_20d = −0.19`。
> **有效独立维度约 2.4 个，不是 3 个**——对外说"多维度"要带这个限定。

## 6. 仓位管理：成交量斜率档位

```python
slope  = LINEARREG_SLOPE(index_volume, W)     # 14:30 那根 bar 的值
score  = 1 if slope > 0 else 0
mult   = 1.0 if score.shift(1) > 0 else 1/16  # 用前一交易日结论
```

| 池 | 基准指数 | 窗口 W |
|---|---|---|
| 大盘池 | 沪深300（000300） | 102 根 30 分钟 bar（≈13 天） |
| 小盘池 | 国证2000（399303） | 72 根（≈9 天） |

**为什么保留**：P0 复核做了安慰剂检验——保持每池"高档日"数量不变、随机重排"哪几天高档"，
重复 2000 次：

| | 净年化 | Sharpe |
|---|---|---|
| **真实档位** | **+9.59%** | 0.71 |
| 安慰剂（随机时点） | 中位 −3.05%（5%~95% 区间 −10.8% ~ +6.1%） | ≈ −0.15 |
| 满档（不择时） | −9.86% | −0.25 |

真实值落在安慰剂分布 **第 98.8 分位**。**这是全套三层里唯一通过安慰剂检验的层。**

> 它不是 alpha，是风险开关：2024 与 2026 两个最危险的年份，它把敞口从 0.96 压到 0.29。

## 7. 决策器（V7 默认关闭，仅研究）

```python
disp  = IQR(ret_5d) 的截面四分位距          # 全池合并
pct   = disp 在过去 120 日的扩展分位
use_v1 = pct < 0.5                           # 低分化用 V1，否则用 V3
```

**为什么默认关闭**：

| 证据 | 数字 |
|---|---|
| CSCV/PBO（11 个参数格，252 条路径） | **PBO = 56.3%**（等于抛硬币） |
| 禁运 120 日后样本外 Sharpe | 0.97 → **0.49** |
| WFV 逐年重选参 | 2025 选 W120，2026 选 W250（漂移） |
| 2026 年超额 | 全部来自 2026-03-24 单日；剔除后跑输纯 V3 3.5pp |
| 触发质量 | 204 次触发中位数 **−0.21bp**（靠单日大赢撑均值） |

保留代码是为了**继续观察**，不是因为它能赚钱。

## 8. 权重与执行

```
池预算 = 0.96 × 池占比 × 档位(1.0 / 1/16)
单票   = 池预算 / 4
若单票 > 19% → 压到 19%，超额在池内再分配
```

| 池 | 池占比 | 每池只数 | 高档单票 | 低档单票 |
|---|---|---|---|---|
| 大盘 `mac` | 30% | 4 | 7.2% | 0.45% |
| 小盘 `min` | 70% | 4 | 16.8% | 1.05% |

**成本**：单边 0.1%（佣金 2.5bp + 印花税 5bp + 滑点）。每日全换：
`日成本 = 0.1% × (今日敞口 + 昨日敞口) ≈ 0.064%/日 ≈ 16%/年`。

**盈亏平衡线**：每单位敞口的日收益必须 > **0.200%**。V7 当前 **0.306%**（安全垫 0.106%）。

## 10. 风险与边界

### 10.1 已知风险

1. **成本极敏感**：每多 5bp/边，年化掉约 8pp；13:30 出场的全部增量正好被 5bp 吃掉。
2. **样本外已经失效**：2025-07 之后三因子模型跑不过随机选股（SR 0.124 vs 0.160）。
3. **因子叙事要改**：`amihud` 不是独立的流动性溢价，正交后归零。
4. **收益集中**：剔除最好 5 天即归零。
5. **边界薄**：rank4−rank5 的 score gap 中位数只有 0.028（z 单位），39% 的交易日小于均值一半。
6. **容量小**：单点出货、8 只票，5% 参与率下 AUM 上限约 600 万。

### 10.2 适用边界

| 适用 | 不适用 |
|---|---|
| 规模 ≤ 1000 万 | 规模 5000 万以上 |
| 可承受 25% 回撤 | 要求月度正收益 |
| 投资周期 ≥ 12 个月 | 3 个月内考核 |
| 能接受小盘风格暴露 | 需要风格中性 |

### 10.3 上线前提

- [ ] 用实盘成交价重算成本（尤其 13:30 的卖出腿）
- [ ] 纸面跟踪 ≥ 3 个月，对比 `wpqc_v7_signal.csv`
- [ ] 检查持仓日均成交额是否覆盖下单量
- [ ] 参数冻结：窗口 20、阈值 ±3、N=4、档位 1/16 不再变动
- [ ] 设定退出条件：连续 6 个月跑输等权基准，或 IC 连续 2 季度低于全样本一半
