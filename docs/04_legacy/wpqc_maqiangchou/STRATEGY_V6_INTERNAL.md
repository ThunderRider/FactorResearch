## 0. 一页看懂

V6 是**三层结构**：

```
第 1 层  选股（两套并行）
        ├── V1 线：RESI + rolling_coef_std 的两段式排序（3 只/池）
        └── V3 线：vol_ratio + amihud[T-1] + ret_20d 的 z-score 合成（4 只/池）

第 2 层  选择（决策器）
        └── 截面离散度（ret_5d 的 IQR）的历史分位 < 0.5 → 用 V1，否则 → 用 V3

第 3 层  仓位（档位）
        └── 指数 30 分钟成交量的线性回归斜率符号 → 1.0 / (1/16)
```

固定不变的部分：T 日 14:45 买入、T+1 日卖出、每日全换手、两个股票池、单票 19% 上限。

## 1. 数据与预处理

### 1.1 数据源

* 米筐 rqdatac，30 分钟 bar，`adjust_type='post'`（后复权）；
* 股票池：大盘池 = 沪深300 + 中证500，小盘池 = 中证1000 + 中证2000，剔除 ST；
* 历史区间：2023-08-13 起（滚动窗口预热需要约 40 根 bar）。

### 1.2 每日快照（30 分钟 bar → 一行）

一天 8 根 bar，只保留会用到的时点（rqdatac 的 bar 以**结束时间**标记）：

| bar 时点 | 实际区间 | 取什么 | 用途 |
|---|---|---|---|
| 10:00 | 9:30–10:00 | `open` | 当日开盘价（算隔夜跳空） |
| 11:00 | 10:30–11:00 | `close` | 出场价之一 |
| 11:30 | 11:00–11:30 | `close` | 出场价之一 |
| 13:30 | 13:00–13:30 | `close` | 可选出场价 |
| 14:00 | 13:30–14:00 | `close` | 尾盘动量 |
| 14:30 | 14:00–14:30 | `close` / `volume` | 决策主时点 |
| 15:00 | 14:30–15:00 | `close` | 当日收盘 |

聚合字段：当日最高、最低、总成交额（`total_turnover` 求和）。

### 1.3 关键预处理：交易日历对齐

```python
full = MultiIndex.from_product([全部股票, 全部交易日])
snap = snap.reindex(full)
```

**为什么必须做**：停牌日没有 bar。若不补齐，后面的 `shift(-1)` 会跳到"下一个有数据的日子"，
收益口径会悄悄变成"持有了好几天"。补齐后停牌日为 NaN，`shift` 按交易日推进，计算自然正确。

## 2. V1 线：两个"波动物价"因子

### 2.1 RESI —— 去趋势后的波动幅度

**构造**

```
K_price   = (high + low + close) / 3          # 典型价
lnK       = log(K_price)
fit       = LINEARREG(lnK, window=40)         # 40 根 bar 的线性回归拟合值
residual  = lnK − fit                          # 残差
RESI      = rolling_std(residual, 40)          # 残差的 40 根滚动标准差
```

代码骨架：

```python
y   = np.log((bars.close + bars.high + bars.low) / 3)
fit = talib.LINEARREG(y, timeperiod=40)
resi = pd.Series(y - fit).rolling(40).std()
```

**逻辑**：把"价格上涨/下跌的趋势"用一条直线拟合掉，剩下的残差就是"没有趋势解释的波动"。
残差越大，说明这只票在趋势之外还在剧烈晃动。取 40 根 bar（约 5 个交易日）的残差标准差，
得到"单位时间内的结构性波动"。

**参数**：窗口 40 根（≈5 个交易日）。实测 40 根优于 80/160 根（IC −0.058 vs −0.053 vs −0.045），
短窗口更贴近 20 小时的持有期。

**已知缺陷**：RESI 有量纲，会随个股波动率等比放大——**它本质上是个"高波动"代理**，
与 20 日波动率的相关性 0.72。这意味着"RESI 大"约等于"这票波动大"，而不是"这票结构好"。
（这也是后来做了 `resi_norm = RESI / σ(lnK) ≈ √(1−R²)` 的原因，但实测归一化后 IC 归零，
说明它的预测力 100% 来自波动率本身。）

### 2.2 rolling_coef_std —— 量价关系的稳定度

**构造**

```
lnV        = log(volume)
corr       = rolling_corr(lnK, lnV, window=40)   # 价格与成交量的滚动相关系数
coef_std   = rolling_std(corr, 40)               # 相关系数序列的 40 根滚动标准差
```

**逻辑**：量价关系如果一直在变（相关系数忽正忽负），说明资金进出没有章法；
如果量价关系稳定（相关系数常年接近某个值），说明有稳定的资金在做。
取相关系数序列的波动率，越小越"稳定"。

**已知缺陷**：
1. **对符号不敏感**：一只票量价持续背离（corr ≈ −1）也会被判为"最稳定"；
2. **相关系数接近 ±1 时 std 天然趋 0**，会产生伪稳定。
   改进方向是用 `corr(ΔlnP, ΔlnV)` 替代 `corr(lnP, lnV)`（实测 IC 从 −0.009 提升到 −0.050），
   以及用相关系数的均值/符号做二次约束。

### 2.3 两段式选股

```python
# 大盘池：先按 RESI 降序取前 10，再按 coef_std 升序取前 3
first  = df.sort_values('RESI', ascending=False).groupby('date').head(10)
second = first.sort_values('coef_std', ascending=True).groupby('date').head(3)

# 小盘池：方向相反
first  = df.sort_values('coef_std', ascending=False).groupby('date').head(10)
second = first.sort_values('RESI', ascending=True).groupby('date').head(3)
```

**逻辑**：
* 大盘池要"波动大 + 量价关系稳" → 高弹性但资金有章法；
* 小盘池要"量价关系剧烈 + 波动小" → 资金正在换手但价格没被炒高。

**已知问题**：
1. **第 11 名直接出局**，边界极不稳定（1 只票的排名变化就会换掉整个组合）；
2. 两池方向相反、斜率窗口不同（102 / 72），参数自由度偏高；
3. 实测小盘池的这套规则是**负贡献**（选股超额 −0.033%/日，t=−0.64）。

## 3. V3 线：三个"横截面"因子

V3 与 V1 最大的区别：**不再用两段式，而是三个因子各自标准化后相加**。

### 3.1 vol_ratio —— 同时刻量比

```
v1430      = 当日 14:00–14:30 的成交量
v_ma20     = rolling_mean(v1430, 20, min_periods=10)   # 过去 20 个交易日同一时点的均量
vol_ratio  = v1430 / v_ma20
```

**逻辑**：A 股成交量有强烈的 U 型日内季节性（开盘、收盘放量，中午缩量）。
若用"今日全天量 / 过去 20 日全天量"，季节性会污染信号；
用**同一时点**的 20 日均量做分母，天然消掉季节性。

**方向**：量比越小越好（正向打分时取负号）。含义是"今天没人关注这只票"——
冷门股在次日更容易被资金重新发现。

**实测**：小盘池 IC −0.048（t=−14.6），是全部因子里最强的；分层 q10−q1 = −38.5bp/日。

### 3.2 amihud —— 非流动性（滞后一天）

```
daily_ret  = c1500 / c1500.shift(1) − 1          # 15:00 收盘的日收益
amihud_t   = |daily_ret| / day_amt               # day_amt = 当日总成交额
amihud     = rolling_mean(amihud_t, 20, min_periods=10)
amihud_lag = amihud.shift(1)                     # ← 关键：滞后一天
```

**逻辑**（Amihud, 2002）：单位成交额能推动多少价格，衡量盘口深度。
越大越"冷门/流动性差"，未来收益溢价越高。

**为什么要滞后一天**：当日 amihud 用到 15:00 收盘价和全天成交额，而决策在 14:45——
这是 **15 分钟前视**。改成 T−1 口径后，回测反而更好（+2.5pp），
因为它本质是"冷门溢价"，不需要当天信息。

**方向**：越大越好。实测小盘池 IC +0.033（t=+6.4）。

**重要警告**：amihud 与市值强负相关。做过测试：把 amihud 对 `log(20日均成交额)` 正交化后，
毛收益从 24.5% 降到 18.3%；直接删掉 amihud 降到 13.9%。
也就是说 **amihud 贡献的 10.6pp 里，约 4.4pp 是真·流动性溢价，约 6.2pp 是市值暴露**。

### 3.3 ret_20d —— 20 日反转

```
ret_20d = c1430 / c1430.shift(20) − 1
```

用 14:30 的收盘价，因为决策在 14:30 之后。窗口 20 个交易日。

**逻辑**：A 股在中短周期呈现强烈的截面反转（散户处置效应 + 过度反应）。
20 日涨幅越大，未来 20 小时越容易回落。

**方向**：取负号（跌得多的买）。实测小盘池 IC −0.052（t=−7.95），
但 2026 年衰减到 −0.025。

### 3.4 合成打分

```python
for f in ['vol_ratio', 'amihud_lag', 'ret_20d']:
    z = df.groupby(['pool','date'])[f].transform(
            lambda s: ((s - s.mean()) / s.std()).clip(-3, 3))
score = (-z_vol_ratio + z_amihud_lag - z_ret_20d) / 3
picks = score 每池前 4
```

**为什么用 z-score 而不是百分位秩**：
z-score 保留"离均值多远"的信息，百分位秩会把差异压平。
实测 z-score 优于秩（V3 三因子：25.6% vs 15.9% 毛年化），但优势主要来自尾部。

**为什么截尾 ±3**：防止单个极端值主导打分。截尾阈值做过 ±2 / ±3 的敏感性测试，
±2 会砍掉太多信息（毛收益降到 15.6%），±3 是比较好的折中。

**为什么三个等权**：没有证据支持某个因子应该更高权重；等权最不容易过拟合。

### 3.5 三因子的逐年 IC（总收益口径）

| 因子 | 2023 | 2024 | 2025 | 2026 | 全样本 |
|---|---|---|---|---|---|
| vol_ratio | −0.036 | −0.034 | −0.032 | −0.025 | **−0.048** |
| amihud(T−1) | +0.014 | +0.005 | +0.010 | +0.020 | **+0.033** |
| ret_20d | −0.039 | −0.039 | −0.064 | −0.025 | **−0.052** |
| RESI（V1） | −0.052 | −0.047 | −0.050 | −0.055 | −0.058 |
| coef_std（V1） | −0.011 | −0.007 | −0.006 | −0.006 | −0.009 |

**读法**：`vol_ratio` 和 `amihud` 四年方向稳定；`ret_20d` 强度在 2026 年明显衰减；
`coef_std` 基本没有信息量（IC 只有 −0.009）。

## 4. 决策器：用离散度决定用哪条线

### 4.1 构造

```python
# 全池（两个池合并）的截面离散度
disp  = IQR(ret_5d)               # 当日所有股票 ret_5d 的四分位距 = Q75 − Q25
pct   = expanding(120).rank(disp) # 扩展窗口分位，只用当日及历史
use_v1 = pct < 0.5
```

其中 `ret_5d = c1430 / c1430.shift(5) − 1`。

### 4.2 逻辑

* **低分化**（IQR 小）→ 股票同涨同跌 → V1 的"高弹性"更容易跑出超额；
* **高分化**（IQR 大）→ 个股差异大 → V3 抓"错杀修复"更有效。

### 4.3 为什么用 IQR 而不是标准差

`ret_5d` 的截面分布有厚尾（涨跌停、停牌复牌），标准差会被极端值主导；
四分位距只看中间 50% 的股票，对这个用途更稳健。

### 4.4 参数选择

| 参数 | 取值 | 依据 |
|---|---|---|
| 离散度口径 | `IQR(ret_5d)` | 24 组网格里，只有这一族样本外 6/6 为正；`IQR(ret_20d)`、`std(ret_5d)`、`std(ret_20d)` 三族基本全负 |
| 分位窗口 | 120 日 | 60/120/250 都测过，结果接近，120 居中 |
| 阈值 | 0.5 | 0.4/0.5/0.6 都测过，0.5 与 0.6 都不错，0.4 明显差；选 0.5 因为它是中位数、最中性 |

### 4.5 触发质量（重要）

204 次触发（占 26.9% 的交易日）：

| 期间 | 次数 | 日均超额 | 累计 | 胜率 |
|---|---|---|---|---|
| 2024 | 60 | +6.1bp | +3.66pp | 55.0% |
| 2025 | 119 | +6.0bp | +7.13pp | 46.2% |
| 2026H1 | 12 | +33.6bp | +4.04pp | 58.3% |
| 2026H2 | 13 | −21.9bp | −2.85pp | 30.8% |

**全样本均值 +6.0bp，但中位数 −0.21bp**——说明它不是"稳定小赢"，而是"多数小亏 + 偶尔大赢"：
最大的一次（2026-03-24）贡献 +450bp，把整条均值曲线抬了起来。
2026 年全年 +0.85pp 的超额全部来自这一天，剔除后跑输纯 V3 3.5pp。

**结论**：决策器目前只支持"观察"，不支持"下注"。实盘默认建议 `--mode v3`。

## 5. 档位：唯一的择时层

### 5.1 构造

```python
# 指数 30 分钟成交量
slope = talib.LINEARREG_SLOPE(index_volume, timeperiod=W)
# 取 14:30 那根 bar 的值；NaN→NaN，<0→0，>0→1
score = np.where(np.isnan(slope), np.nan, np.where(slope < 0, 0.0, 1.0))
# 关键：用前一交易日的结论
score_1 = pd.Series(score).shift(1)

# 仓位倍数
mult = 1.0 if score_1 > 0 else 1/16
```

| 池 | 基准指数 | 窗口 W |
|---|---|---|
| 大盘池 | 000300（沪深300） | 102 根 bar（≈13 个交易日） |
| 小盘池 | 399303（国证2000） | 72 根 bar（≈9 个交易日） |

### 5.2 逻辑

指数成交量在放大（斜率 > 0）说明资金在进场，策略的有效性高，满仓；
成交量在萎缩说明资金在撤，策略容易失效，仓位压到 1/16。

**为什么是 14:30 那根 + shift(1)**：14:30 的 bar 已经收完，14:45 决策时可知；
shift(1) 保证用的是"昨天的结论"，避免任何时点上的歧义。

### 5.3 实证：它是全套策略里最结实的一层

| 年份 | 带档位净 | 永远满仓净 | 档位贡献 |
|---|---|---|---|
| 2023 | +3.61% | +6.05% | −2.44pp |
| 2024 | +15.79% | −11.37% | **+27.16pp** |
| 2025 | +8.89% | +16.24% | −7.35pp |
| **2026** | **+0.77%** | **−32.96%** | **+33.73pp** |
| 全样本 | +31.62% | −26.75% | **+58.37pp** |

**它不是每年都加分**（2023、2025 是拖累），但在 2024 和 2026 这两个最危险的年份救了命。

### 5.4 分池有效性（每单位敞口日收益，bp）

| 年份 | 池 | 高斜率日 | 低斜率日 | 判定 |
|---|---|---|---|---|
| 2024 | 大盘 | +24.8 | +32.3 | 反向 |
| 2024 | 小盘 | **+54.0** | **−6.3** | 准 |
| 2025 | 大盘 | +27.4 | +14.8 | 准 |
| 2025 | 小盘 | +38.3 | +28.8 | 弱准 |
| **2026** | 大盘 | **−8.3** | **+4.6** | **反向** |
| **2026** | 小盘 | **+83.4** | **−12.3** | **极准** |

2026 年小盘池的斜率信号极强（高斜率日 +83bp、低斜率日 −12bp），
但大盘池反了。**不要因此把大盘池反向**——那会牺牲 2025（+8.89% → +4.47%），是典型的单年拟合。

### 5.5 Excel 斜率口径的陷阱

`slope_window` 是 **30 分钟 bar 数**，不是天数（102 根 ≈ 13 天、72 根 ≈ 9 天）。

若改用自然日做横轴（Excel `SLOPE(volume, 日期)` 的做法）：
* mac 池符号一致率 89.5%，min 池只有 **77.4%**（181/800 天翻转）；
* 回测后果：V3 净 9.55% → **−1.37%**（因为高档日变多，敞口 0.32 → 0.49，成本翻倍）。

**结论：不要用自然日横轴。** 要复核请在 Excel 里用"第 N 根 bar"做 x 轴。

## 6. 可交易性过滤

在打分之前先剔除不可成交的标的：

```python
gap      = o1000 / c1500.shift(1) − 1        # 隔夜跳空
intraday = c1430 / o1000 − 1                 # 开盘到 14:30
day_ret  = (1 + gap) × (1 + intraday) − 1    # 当日累计涨幅（截至 14:30）

mask = (|day_ret| < 9.5%)        # 剔除涨停/跌停（无法按收盘价成交）
     & (v1430 > 0)               # 剔除停牌/无成交
     & (amt20 > 5e7)             # 剔除流动性太差（20 日均成交额 < 5000 万）
```

**为什么必须做**：不加过滤时，用 `gap` 排序能跑出 **+14,807%/年**——
因为它选出的全是"开盘涨停"的股票，这些票根本买不进。
加上过滤后，单独用 `gap` 排序是 **−81.5%**。

## 7. 权重与执行

### 7.1 权重

```python
# V1 线：0.96 × 50% × 档位 / 3 只
# V3 线：0.96 × (大盘 30% 或 小盘 70%) × 档位 / 4 只
# 单票上限 19%，超额在池内再分配
```

| 线 | 池占比（大/小） | 每池只数 | 高档单票 | 低档单票 |
|---|---|---|---|---|
| V1 | 50% / 50% | 3 | 16.0% | 1.0% |
| V3 | 30% / 70% | 4 | 7.2% / 16.8% | 0.45% / 1.05% |

### 7.2 执行

* T 日 14:45 按目标权重买入（市值等权）；
* T+1 日 11:15（或 13:30）全部清仓；
* 每日循环，日换手 100%。

### 7.3 成本

单边 0.1%（佣金 2.5bp + 印花税 5bp（卖出）+ 滑点）。因每日全换：
`日成本 = 0.1% × (今日敞口 + 昨日敞口) ≈ 0.067%/日 ≈ 17%/年`。

**盈亏平衡线**：每单位敞口的日收益必须 > **0.200%**。
V3/V6 当前是 0.315%/日，安全垫 0.115%。

## 8. 已证伪：不要再试的因子

| 方向 | 结论 |
|---|---|
| MAX 彩票因子（20 日最大单日涨幅） | IC −0.051 稳定，但与 20 日波动率相关 **0.874**，是波动率的马甲；过滤/加权/替换 9 种用法全部变差 |
| 隔夜/日内解耦 | `ov_20` IC +0.017、`in_20` IC −0.026，但 `ov+in ≈ ret_20d`，重复计权，加入后毛收益 24.5% → 14.0% |
| 波动率进仓位管理（3×3） | 只用波动率管仓位时敞口飙到 0.81、年成本 41%，V1/V3/V4 全部 −10%~−20% |
| 档位置信度加权 | 连续加权 0.4~1.0 让 V3 净收益 9.55% → 7.00%；对照实验证明"无脑整体降仓 ×0.73"更好（Sharpe 0.69 vs 0.63） |
| 分数置信度过滤 | 表面分档单调，按档位分层后完全不单调（相关性 −0.039）——辛普森悖论 |
| 市值分层 | V4 持仓平均市值分位仅 0.179；分层后收益掉 4~12pp，回撤反而变大 |
| 行业动量 | 全样本 27.1%，但 2024 单年贡献 20.3%，样本外 −11.9% |
| 行业内反转 | 收益持平，MDD 改善 4pp，但样本外更差（−12.7% vs −8.5%） |
| 行业内每池 1 只 | 过度分散，收益掉 4.8pp |

**唯一值得保留的是"行业 ≤2 只"**：几乎零成本（−0.6pp），把单行业最大持仓从 4 只降到 2 只。

## 9. 实现层面的坑（都踩过）

| 坑 | 现象 | 处理 |
|---|---|---|
| **停牌未对齐日历** | `shift(-1)` 跳到下一个有数据日，收益变成"持有好几天" | 按全交易日 × 全股票 reindex |
| **15 分钟前视** | amihud 用当日 15:00 收盘价，但 14:45 就决策 | amihud 滞后一天 |
| **涨停污染** | gap 排序选出开盘涨停票，回测 +14,807% | 可交易过滤 + 不使用 gap 打分 |
| **Excel 斜率口径** | 自然日横轴让 min 池 23% 的信号翻转 | 用 bar 序号做 x 轴 |
| **分组键缺池** | 两池预算不同，按 (日期,策略) 分组会把小盘池的仓位吃掉 | 按 (日期, 策略, 池) 分组 |
| **预热期默认值** | 趋势门在预热期默认 0.5 仓位，恰好躲过 2024 年初的股灾，制造虚假的 MDD 改善 | 预热期设为 1.0（不折扣） |
| **抽签式换仓** | 两段式第 11 名直接出局，组合跳变 | 改用连续打分（V3） |

## 12. 最后三句提醒

1. **这套东西的 alpha 是真的**（对基准超额 t=3.40），但它被成本和敞口摊薄了——
   评价它要看"每单位敞口日收益"（现在 0.315%），不要看年化。
2. **档位是命门**。去掉档位，2026 年从 +0.8% 变 −33%。任何改动都不能动档位。
3. **决策器是观察项，不是下注项**。它的中位数超额已经是负的，靠单日大赢维持均值。
