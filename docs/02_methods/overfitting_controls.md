# 防过拟合控制：DSR / PBO / 禁运 / 置换

> 门 6 的展开。**核心问题：这个结果里，有多少是"真的"，有多少是"我搜了多少次"的产物？**
> 代码：`factorlab.audit.{dsr, pbo, purge, permutation, trials}`

## 0. 为什么要单独一层

旧项目 `OVERFITTING_TESTS_V6.md` 的自我诊断值得抄下来：

> "这套策略不是'没做过防过拟合'，而是'防过拟合做在了错误的层，且缺三件审计工具'。"

它做对的（**结构红利**，不是审计）：

1. 结构极简（三因子等权、z 截尾、无 ML）→ "死记硬背噪音的模型"在结构上不可能出现
2. 时间顺序回测（无 shuffle、无随机切分）
3. 决策器做过安慰剂（随机切换 3000 次，全样本第 87.8 分位——**它自己承认了不显著**）
4. 证伪清单很长，每条都有对照数字

它缺的（**审计层**，全部缺失）：

| 工具 | 现状 |
|---|---|
| N 记账 | 无（事后清点出 ≈110） |
| DSR | 无 |
| PBO / CSCV | 无 |
| Purging / Embargo | 无 |
| 置换重要性 PI | 无 |
| 脆弱性曲线 | 只有定性一句 |

**结论：把防过拟合做在"结构"上是对的，但"结构好"不能替代"审计"。**
简单模型不需要担心过拟合 —— 这句话是错的，它只不需要担心**某一类**过拟合。

## 1. N 记账：一切的前提

### 1.1 记什么

```csv
run_id,date,hypothesis,object,params,sample,metric,value,passed,notes,script,git_sha
```

| 列 | 说明 |
|---|---|
| `run_id` | `<YYYYMMDD>-<slug>`，与 results 目录一致 |
| `hypothesis` | 一句话说明这次在验证什么 |
| `object` | 被检验的对象（因子 / 决策器 / 仓位层 / 出场时点） |
| `params` | 参数组合（网格搜索时每个格子一行） |
| `sample` | 区间 |
| `metric`,`value` | 主指标与值 |
| `passed` | `pass` / `fail` / `tbd` |
| `script` | 复现入口 |

### 1.2 什么算"一次试验"

**任何一次让你的判断可能改变的运行，都是试验。** 包括：

- 改参数（窗口、阈值、截尾）
- 改定义（用 14:30 还是 14:00 bar）
- 改样本区间
- 改成本假设后重看结论
- **失败的、放弃的、没写进报告的那些**

**不算试验**：纯工程性重跑（同样的代码、同样的数据、只是修了 bug）。

### 1.3 为什么这么严

```
DSR 的分母是 N。N 少记一次，DSR 就虚高一次。
```

旧项目的对照：

| N \ σ(SR) | 0.15 | 0.25 | 0.35 |
|---|---|---|---|
| 1（不惩罚） | 0.896 | 0.896 | 0.896 |
| 24 | 0.767 | 0.646 | 0.509 |
| 60 | 0.736 | 0.584 | 0.418 |
| **120（接近真实）** | 0.714 | **0.540** | 0.358 |
| 200 | 0.698 | 0.510 | 0.319 |

**同一个策略，N=1 时 PSR=0.90，N=120 时 DSR=0.54。门槛 0.95。**
"这个夏普是不是搜索的产物"完全取决于你记了多少笔账。

### 1.4 一个反直觉的事实

> **每做一次"防过拟合测试"，N 就涨一次。**

旧项目本轮做了置换（3 因子 × 100 次 × 2 窗口 = 600）、边界随机（200 次）……
把随机抽样也计入后，**真实 N 已超过 900**。

这不是悖论，是提醒：**审计工具本身也在搜索空间里**。
所以 `trials_log.csv` 才是这套流程里最该长期维护的文件，而不是最该省的文件。

## 2. DSR（Deflated Sharpe Ratio）

### 2.1 是什么

Bailey & López de Prado：你观察到的最大夏普，是从 N 次试验里挑出来的**最大值**，
它的期望值本身就偏高。DSR 把"挑最大值"的期望扣掉，再算一次"显著吗"。

```
SR*  = 期望最大夏普（由 N 与 σ(SR) 决定）
DSR  = PSR(SR*, T, skew, kurt)
```

### 2.2 需要的四个配料

| 配料 | 从哪来 |
|---|---|
| `SR` 观测夏普（年化） | 回测 |
| `T` 样本长度 | 交易日数 |
| `skew`, `kurt` | 日收益的偏度、峰度 |
| **`N` 试验次数** | `trials_log.csv` |
| **`σ(SR)`** 全部试验 SR 的横截面标准差 | `trials_log.csv` |

**`σ(SR)` 是旧项目缺的那一项** —— 因为没记账，只能给敏感性网格。
有了 `trials_log.csv`，DSR 从"估算"变成"读数"。

### 2.3 用法

```python
from factorlab.audit.dsr import deflated_sharpe
dsr = deflated_sharpe(daily_returns, n_trials=120, sigma_sr=0.25)
# → {'sr': 0.71, 'psr': 0.90, 'dsr': 0.54, 'pass': False}
```

### 2.4 门槛与读法

| DSR | 含义 |
|---|---|
| **> 0.95** | 通过。在 N 次搜索后，这个夏普仍不太可能是运气 |
| 0.7 ~ 0.95 | 灰色地带。可以继续研究，**不能写进业绩预期** |
| < 0.7 | 大概率是搜索的产物 |

### 2.5 注意

- **DSR 惩罚的是"搜索"，不是"策略"。** 一个 DSR 低的策略可能是真的好，只是你的证据不够。
- **合并不同策略的 DSR 时 N 要累加。** 你测了 120 个因子挑出最好的那个，N 就是 120，不是 1。
- 参数冻结的规则型策略（不选参、不重训）依然要算 DSR —— 因为**"选择这套规则"本身就是一次选择**。

## 3. PBO / CSCV（路径依赖）

### 3.1 是什么

把样本切成 S 块（通常 10），穷举所有"S/2 块当 IS、S/2 块当 OOS"的对称组合
（C(10,5)=252 条路径）。每条路径上：

```
用 IS 挑出冠军 → 看它在 OOS 的排位
PBO = 冠军落到后 50% 的概率
```

### 3.2 读法

| PBO | 含义 |
|---|---|
| < 0.2 | 选参流程稳健 |
| 0.2 ~ 0.5 | 有风险 |
| **> 0.5** | **等于抛硬币**，"样本内最优"没有意义 |

> 旧项目：决策器 PBO = **56.3%**，logit 中位数 −0.18。
> 正式判定"不通过"，与"安慰剂 87.8 分位（不显著）"互相印证。
> **PBO 的价值在于它是可写进尽调材料的正式指标，比"分位"更硬。**

### 3.3 什么时候可以跳过

**参数冻结、不选参、不重训的策略**可以跳过 PBO，因为 PBO 检验的是"选参流程"。

但**必须在材料里说明为什么跳过**：

> ❌ "我们没有做 PBO"
> ✅ "参数在 V6 冻结（窗口 120 / 阈值 0.5 / IQR5 定义都不再变），因此没有可重选的参数，
>     PBO 这一项在技术上退化；相应地，我们做了 DSR(N=120) 与档位安慰剂。"

### 3.4 顺带一个"反优化"的证据

旧项目发现：全样本 SR 最高的是 `T=0.6`（0.97），但文档选了中性 `T=0.5`（0.91）。

**这是"主动放弃最优点、选了最稳点"——这条要写进材料，它是"我们没在调参"的硬证据。**

如果你有过类似的时刻，**记下来**。它比任何"我们没有过拟合"的声明都有说服力。

## 4. Purging / Embargo（边界泄漏）

### 4.1 问题

任何"扩展窗口"的状态变量都会跨越 IS/OOS 边界：

```python
disp_pct = disp.expanding(120).apply(...)     # OOS 前 120 天与 IS 共享信息
```

### 4.2 做法

```
禁运长度 >= 该策略用到的最大特征窗
```

在 IS/OOS 边界处丢弃禁运长度的观测，再重算 OOS 指标。

### 4.3 旧项目的实测

| 切分点 | 禁运 | OOS SR（真实规则） |
|---|---|---|
| 2024-06-28 | 0 | 1.410 |
| 2024-06-28 | **120** | **0.865** |
| 2024-12-31 | 0 | 0.857 |
| 2024-12-31 | **120** | 0.959 |
| 2025-06-30 | 0 | 0.969 |
| 2025-06-30 | **120** | **0.492** |

**"样本外 99.1 分位"这个结论在禁运后不成立** → 旧项目正式撤回了它。

### 4.4 规则

任何写进报告 IS/OOS 的句子，必须包含三个要素：

```
① 切分日期      ② 禁运长度      ③ 禁运后的 OOS 天数
```

> ❌ "样本外显著（99.1 分位）"
> ✅ "2025-07-01 起为样本外，禁运 120 个交易日，OOS 有效 202 天，Sharpe 0.49"

## 5. 置换重要性（Permutation Importance）

### 5.1 做法

把某个因子的**截面值**随机打乱（保留其余因子、池、日期结构），用同一个选股规则重跑组合：

```python
for _ in range(100):
    shuffled_z = permute_within_group(z_factor, by=['date','pool'])
    sr_perm = run_portfolio(shuffled_z)
ΔSharpe = SR_base - mean(SR_perm)
```

### 5.2 必须有的对照

| 变体 | 用途 |
|---|---|
| 基准（全部因子） | 出发点 |
| 打乱某因子 | 该因子的贡献 |
| **噪声占一槽**（随机数列替换） | **校准"多一列噪声的代价"** |
| 全噪声选股 | 极端对照：策略的"零信息"基线 |

> **为什么必须有"噪声占一槽"**：旧项目测出"打乱 amihud，净年化从 +9.6% 掉到 −4.0%"，
> ΔSR=0.98，看起来 amihud 极其重要。
> 但"噪声占一槽"的对照也掉了 **ΔSR=0.67**。
> **所以净信息量只有约 0.31 的 ΔSR，不是 0.98。**
> 不给对照，所有 PI 数字都会系统性高估 2–3 倍。

### 5.3 判定线

```
ΔSharpe > 0.10（扣除噪声对照后）
```

旧项目 `coef_std` 这类 IC −0.009 的因子，预计会直接归零。

### 5.4 最有价值的发现往往在 OOS

旧项目同一套 PI 在 OOS（2025-07 之后）给出的结果：

| 变体 | OOS 净年化 | OOS Sharpe |
|---|---|---|
| 基准（三因子） | 1.11% | 0.124 |
| 打乱 amihud | −13.03% | −1.513 |
| **全噪声随机选股** | **1.41%** | **0.160** |

**因子在样本内有信息，但 2025-07 之后三因子模型跑不过"随机选 4 只"。**
这不是"因子弱"，是"这几年小盘冷门溢价的 beta 本身没了"。

**必须看 OOS 的 PI，不只看全样本的。**

## 6. 安慰剂检验（Placebo）

### 6.1 什么时候用

当被检验的对象是一个**"选日子"的规则**（择时、仓位档位、切换器），
置换重要性不适用（它打乱的是截面值，不是时点）。

安慰剂的做法：**保持"用几次"不变，随机化"哪几天用"**。

```python
# 真实：档位在 160 天为 1.0，其余为 1/16
# 安慰剂：随机选 160 天为 1.0，重复 2000 次
```

### 6.2 读法

```
真实值落在安慰剂分布的第 X 分位
```

| 分位 | 含义 |
|---|---|
| > 95% | 通过，确实在"选日子"而非"随机少下注" |
| 80~95% | 弱证据 |
| < 80% | 不通过。它只是"仓位小"，没有时点信息 |

> 旧项目：
> - **决策器**：全样本第 87.8 分位（不显著），OOS 第 99.1 分位（但禁运后不成立）→ 判"研究记录"
> - **档位（成交量斜率）**：**第 98.8 分位（Sharpe 第 97.6 分位）** → 通过，这是全套里唯一通过安慰剂的层
>
> 附带一个重要读法：安慰剂的**中位数是 −3.05%**，
> 说明"少下注"本身不创造价值，**价值全在时点**。

## 7. 多假设控制（BH-FDR）

### 7.1 什么时候需要

当你同时检验很多个假设时：

```
测了 12 个因子 × 4 个收益段 = 48 个假设
→ 在 5% 显著性下，纯随机也会"发现" 2.4 个
```

### 7.2 做法

```python
from statsmodels.stats.multitest import multipletests
reject, p_adj, _, _ = multipletests(p_values, alpha=0.10, method='fdr_bh')
```

### 7.3 判定

留下的因子应能通过 FDR=10%。`close_pos`、`late_mom` 这类预计会被筛掉。

**注意**：FDR 是**廉价的**。它不能替代 DSR（后者惩罚的是搜索空间大小，
FDR 惩罚的是"同时检验的假设数"）。两个都做最好，只做一个至少要做 DSR。

## 9. 一句总结

> **奖励一个策略、惩罚一个搜索。**
>
> 一个简单的三因子模型拿了 0.54 的 DSR，不是因为它简单，是因为你为它付了 120 次试验的代价。
> 一个复杂的机器学习模型拿了 0.9 的 PSR，只要 N 记成 500，DSR 立刻掉到 0.3。
>
> **过拟合不是模型复杂度的问题，是选择次数的问题。**
