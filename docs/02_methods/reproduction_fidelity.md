# 复现口径差异：同一句"V8"能差出 20pp

> **本文解决一个具体问题**：当有人说"我的策略年化 13%"，你要在 5 分钟内判断
> 他的 13% 和你复现出来的 0.04% 差在哪。
>
> 2026-11-24 的实测：同一份 V8 代码 + 同一段 2023-09 之后的行情，**legacy 是 +13.22%，
> 真 PIT 池复现是 +0.04%**。差的不是代码，是口径。

---

## 0. 一张总表

| # | 口径 | 宽松写法（常见） | 严格写法 | 影响方向 | 实测幅度 |
|---|---|---|---|---|---|
| 1 | **池成分** | `index_components(idx, 今天)` 套全历史 | 逐日 `index_components(idx, date)` | 宽松**严重高估** | min 腿 +20.98 → **+42.69bp/日**；组合 +0.04% → +13.22% |
| 2 | **可交易过滤的复权基准** | 30m 价 ÷ 日线昨收 | 同一复权基准内相除 | 混用**随机筛掉样本** | 通过率 0.144 → **0.979** |
| 3 | **进场价** | `(c1430 + c1500)/2` | 决策后第一根 bar 开盘 / VWAP | 宽松**高估** | 未量化（见 §2.3） |
| 4 | **卖出腿滑点** | 不算 | 13:30 口径 +5bp/边 | 宽松**高估** | 每 5bp/边 ≈ 年化 −8pp |
| 5 | **同名不同义的因子** | 都叫 `resi` | 按源码实现 | 可能**完全不同的信号** | IC −0.058 vs −0.066，构造不同 |
| 6 | **改权重时混入资金结构** | 只改只数 | 固定资金结构再改只数 | 混淆**两个效应** | 等权 0.96/(2+N)：mac 占比 33% → 9% |
| 7 | **ST 剔除** | 靠"指数成分不含 ST" | 显式 `is_st_stock` | 轻微**高估** | 未量化 |
| 8 | **停牌 / 涨跌停不可成交** | 只做三条过滤 | 逐日可成交检查 | 轻微**高估** | 未量化 |
| 9 | **标签的 NaN 语义** | 停牌日填 0 收益 | 保留 NaN，不填 | 填 0 = **按 0% 收益成交** | 旧项目实测 1.66pp |
| 10 | **自然日 vs 交易日** | 用日历日做横轴 | 交易日索引 | 小盘池 **23% 信号翻转** | V3 净 9.55% → −1.37% |
| 11 | **样本区间** | 挑表现好的区间 | 全样本 + IS/OOS 切分 | 区间选择**等同于 N** | 本文实测：全样本 −4.08%，2023-09+ 是 +7.25% |

## 1. 第 1 条是最大的坑：池成分

### 症状

```python
# ❌ 宽松：用"今天"的成分套全历史
members = index_components('000852.XSHG', today)   # 2026-05-18 的成分
for d in history_dates:
    select_from(members)                            # 拿 2026 的名单回测 2023
```

### 为什么是偏差而不是"近似"

指数成分是**按表现筛选**的（调样规则里有市值、流动性、上市时长）。
用最终名单回测历史 = **只回测了活下来的赢家**。

### 实测幅度（V8，2023-09-11~2026-05-18，高档日，1115，bp/日）

| 腿 | 逐日 PIT 成分 | 单日最新成分 | 倍数 |
|---|---|---|---|
| mac（2 只） | +23.42 | +39.06 | 1.67× |
| **min（4 只）** | **+20.98** | **+42.69** | **2.03×** |

legacy 报的小盘高档是 **+50.6bp** —— 和"最新成分"的 +42.69 同量级，和 PIT 的 +20.98 差一倍。
**组合层：+0.04%（PIT）vs +13.22%（legacy）。**

### 正确做法

```bash
# 一次拉好逐日成分，落盘备查
python research/2026-11_min_pool_breadth/fetch_universe.py   # 参考实现
# 产出 data/curated/cn_index_pit_universe_<start>_<end>.parquet
# 字段：date, order_book_id, pool, index
```

**验收**：池成分的每日只数应该稳定（mac 800、min 1000→3000），
如果某天突然掉到 60 只，先怀疑对齐问题（见第 2 条）。

## 2. 第 2 条：可交易过滤的复权基准

### 症状

```python
# ❌ 30m 价 ÷ 日线昨收 —— 两个文件可能是不同的复权口径
gap = o1000 / d_close.shift(1) - 1
day_ret = (1 + gap) * (1 + c1430 / o1000 - 1) - 1
tradable = day_ret.abs() < 0.095
```

### 这次踩到的实况

`cn_stock_30m_post_*` 的 `adjust_type = post`（后复权），
`cn_stock_close_*` **没有标 adjust_type**，两者比值的中位数是 **2.85**（本应 1.0）。

后果：`|day_ret| < 9.5%` 只通过 **14.4%** 的样本 —— 相当于随机筛掉 86% 的票，
而过滤后的池看起来"正常"，不会报错，**只会让所有结论悄悄偏移**。

### 正确做法

**同一复权基准内相除**，全部用 30m：

```python
day_ret = c1430 / c1500.shift(1) - 1.0     # ✅ 通过率 0.979
```

### 自检（每次构造面板都跑一次）

```python
dr = (c1430 / c1500.shift(1) - 1).stack().abs()
print(dr.quantile([.5, .9, .99]), (dr < 0.095).mean())
# 期望：中位 ~0、99% < 0.10、通过率 > 0.95
# 若通过率 < 0.5 -> 立刻停下查复权口径
```

## 3. 第 3 条：进场价借了 15 分钟

```python
entry = (c1430 + c1500) / 2     # "≈14:45"
```

`c1500` 是 **15:00** 的收盘价，比 14:45 的决策**晚 15 分钟**。
这是旧项目的**标签约定**（30 分钟 bar 没有 14:45），作为标签是合法的，
但它同时是**执行假设**——真实成交拿不到这个价。

**必做的敏感性**（`registry/labels.yaml` 已列为待做）：
改用「决策后第一根 bar 的开盘」或「14:30–15:00 段的 VWAP」重算，
判定线：**入场假设变化导致下修 < 1pp**。

## 4. 第 4 条：卖出腿滑点

旧项目实测：**每多 5bp/边，年化掉约 8pp**。
13:30 出场相对 11:15 的 +4.3pp 增量，在"卖出腿 +5bp"下**归零**。

报 13:30 口径时**必须同时给 +5bp 版本**，否则等于只报最优口径。

---

## 5. 第 5 条：同名不同义的因子

`resi` 在本仓库有两个完全不同的实现：

| 出处 | 定义 |
|---|---|
| `registry/factors.yaml` / `features/bar_stats.py` | 40 根窗口内 OLS 的**残差标准差**（一次性） |
| `wpqc/strategy01.py`（V1 用的） | `y − LINEARREG40(y)` 得到**每根 bar 的去趋势残差**，**再取 40 根滚动 std** |

两者 IC 量级接近（−0.058 vs −0.066），但**不是同一个统计量**。
引用一个因子的数字前，先确认它的 `formula_code` 指向哪份实现。

---

## 6. 第 6 条：改权重时混入资金结构变化

宽度实验（min 4 → 20 → 50）如果用"全体等权 0.96/(2+N)"：

| N | mac 资金占比 | min 资金占比 |
|---|---|---|
| 4 | 33% | 67% |
| 20 | 9% | 91% |
| 50 | 4% | 96% |

于是"宽度效应"和"资金从大盘挪到小盘"两个效应混在一起。
**必须加一列固定资金结构（33/67）的对照**，否则无法归因。

## 7. 第 7–11 条：其余五条

| # | 检查什么 | 一句话 |
|---|---|---|
| 7 | ST | 指数成分不含 ST 是**大体成立**，不是恒等式；两次调样之间会漏 |
| 8 | 可成交性 | 只有三条过滤（涨幅/量/成交额）≠ 可成交；停牌、涨跌停、复牌首日都要查 |
| 9 | 标签 NaN | 停牌日填 0 = "按 0% 收益成交"，系统性高估 |
| 10 | 时间轴 | 窗口单位必须写进命名（`slope_102bar`），用自然日会让小盘池 23% 信号翻转 |
| 11 | 区间 | 区间选择就是 N；全样本 −4.08% vs 2023-09+ +7.25% 是同一策略 |

## 8. 复用这套代码前的检查清单

[ ] ST / 停牌 / 涨跌停是有显式过滤，还是"假定指数成分没问题"？（§7、§8）

## 9. 谁偏乐观在哪（诚实的自我标注）

| 复现方式 | 偏乐观的地方 | 偏保守的地方 |
|---|---|---|
| **legacy（最新成分）** | 池成分（§1），可能 **+10pp 以上** | — |
| **本仓库 2026-11 的复现（PIT）** | 进场价（§3）、卖出腿滑点（§4）、ST（§7） | 池成分已经是最严的 |

**结论：两边都乐观，但乐观在不同的地方。** 所以：

> **不要把 PIT 复现的数字当成"真实可得收益"，它只是"去掉了幸存者偏差之后的数字"。**
> 真实交易还要再扣进场假设与滑点，幅度未知但方向明确（更差）。
