## 2. RankIC：为什么不用 Pearson

**结论：一律用 Spearman RankIC。**

理由（A 股实测）：

| 原因 | 说明 |
|---|---|
| 极端值 | A 股有涨跌停导致的截断分布，Pearson 被个别大票绑架 |
| 单调性 | 选股关心的是**排序**（选出前 4 只），不是线性关系 |
| 可比性 | RankIC 在不同量纲的因子之间可直接比较 |

**截面内计算，且按池分开**：

```python
ic = panel.groupby(['pool', 'date']).apply(
    lambda g: g[factor].rank().corr(g[label].rank())
)
```

**为什么必须按池分开**：选股发生在池内排序。混池算 IC 会把"池间市值差"当成信号。
旧项目每次都分 `mac` / `min` 两个池报 IC，这是对的。

**最小截面数**：`min_names_per_day = 30`。少于 30 只的那天不算 IC——
否则小样本噪声会让 IC 序列方差爆炸。

## 3. t 值：naive t 会骗你

### 3.1 问题

```python
t_naive = mean_ic / std_ic * sqrt(n_days)
```

这个公式假设**各日 IC 独立**。但因子用的是重叠窗口：

- `ret_20d` → 20 日窗口
- `amihud` → 20 日均值
- `vol_ratio` → 20 日均量基准

相邻两天的 IC 天然相关。naive t 会**系统性高估**。

### 3.2 修正：Newey-West

```python
from factorlab.eval.ic import newey_west_t
t_nw = newey_west_t(ic_series, lag=20)     # lag 取最大重叠窗
```

实测差距（旧项目小盘池）：

| 因子 | mean IC | naive t | **NW(20) t** | IC lag1 自相关 | N_eff |
|---|---|---|---|---|---|
| `vol_ratio` | −0.0478 | −14.59 | **−11.43** | 0.07 | 424 |
| `amihud` | +0.0327 | +6.43 | **+5.48** | 0.12 | 617 |
| `ret_20d` | −0.0520 | −7.95 | **−6.82** | 0.08 | 518 |

naive t 高估 20–30%。

### 3.3 有效样本 N_eff

```
N_eff = n_days × (1 − ρ) / (1 + ρ)      # ρ = lag1 自相关（近似）
```

旧项目把 766 天压到 **424–617 天**。**报告 t 值必须同时报 N_eff**，
否则读者会以为有 766 个独立观测。

### 3.4 块自举

```python
from factorlab.eval.ic import bootstrap_mean_ci
lo, hi = bootstrap_mean_ci(ic_series, block=20, n=3000)   # 均值的 95% CI
# 判定：区间不含 0；`factorlab.eval.run` 已把它写进 ic_summary.csv 的 ci_lo / ci_hi 列
```

重叠窗口下，普通 iid 自举会假性收窄区间。**必须用块自举**，块长 ≈ 最大重叠窗。

**判定线**：95% CI 不含 0。

## 4. 分层：IC 看不出的东西

### 4.1 必报 q1..q10 的 mean **和** median

```python
dec = factorlab.eval.decile.quantile_returns(panel, factor, label, nq=10)
```

**为什么必须给中位数**：A 股分层收益被极端值主导。
旧项目 `amihud` 的 q10−q1 是 +3.9bp（均值），中位数只有 +2.1bp。

### 4.2 看三件事

1. **单调性**：q1→q10 是否大致单调。非单调但有尾部效应，说明因子只在极端段有效
   （旧项目 V8 的边际集中在截面最极端的 **0.1% 尾部**：99.9~100% 分位 +13.3bp/次，其余 −2.2bp）。
2. **多空价差**：`q10 − q1` 的日均 bp。这是"理论最大收益"，要拿它对比盈亏平衡线（20bp 双边）。
3. **分层是否被混杂变量驱动**：见下一节。

### 4.3 ⚠️ 辛普森悖论：分层必须控制市场状态

旧项目踩过：按"当日选中票的平均分"分五档，
最高档 0.227%/日、最低档 0.086%/日，看起来单调有效。

**真相**：分档后再按"仓位档"拆开，高档日**内部**的分数分档完全不单调：

```
33.5 / 29.4 / 3.9 / 21.8 bp    相关性 −0.039
```

高分日恰好大多是高档日 —— **真正起作用的是仓位档，不是分数**。

**规则**：任何"按 X 分层"的结论，必须再控制至少一个市场状态变量（仓位档 / 波动区间 / 涨跌环境）重看一遍。
否则你测的可能是"哪几天的市场好"。

## 5. 覆盖率与失效期

```python
cov = panel.groupby('date')[factor].apply(lambda s: s.notna().mean())
```

必看：

| 指标 | 警戒线 | 为什么 |
|---|---|---|
| 整体覆盖率 | < 60% → 慎用 | 只能在少数票上用 |
| 覆盖率的时间最低点 | < 30% → 查原因 | 常见原因：字段上线晚、停牌、板块缺失 |
| 覆盖率与池的关系 | 差异大 → 查是否有池间偏差 | |

**失效期要单独列出来**：`ret_20d` 在 2026 年 IC 从 −0.052 掉到 −0.029（腰斩），
这不是"随机波动"，是**非平稳**。见 [`../03_knowledge/falsified.md`](../03_knowledge/falsified.md) 的退役规则。

## 6. 相关矩阵：提前发现马甲

```python
corr = panel[factors].corr(method='spearman')
```

| 相关 | 判读 |
|---|---|
| > 0.7（**因子值**相关） | 高度可疑，几乎肯定是同一个东西 |
| 0.3 ~ 0.7 | 有重叠，需做正交化后重看 |
| < 0.3 | 大致独立 |

**注意区分两种相关**：

- **因子值相关**（`corr(f1, f2)`）：直接算的
- **IC 相关**（`corr(ic_daily_f1, ic_daily_f2)`）：更能反映"预测力是否重叠"

旧项目两个都要看：`vol_ratio × ret_20d` 因子值相关 0.34，但 IC 相关更高。
结论是"三因子的有效独立维度约 **2.4 个**，不是 3 个"——
这个数字在尽调时会被追问，"多维打分"的说法撑不住。

## 7. 分年与分区间

```python
by_year = factorlab.eval.stability.by_period(ic_daily, freq='Y')
```

**必报**。判定标准：

- 至少 **3/4 年同向**
- 最弱年份的 IC 不低于全样本的 **50%**

不满足 → 标 `regime-dependent`，不得作为主因子。

> 实例：`ret_20d` 逐年 −0.049 / −0.051 / −0.072 / **−0.029**。
> 前三年稳定，2026 年腰斩 → 触发退役评估。
> 行业动量因子的 2024 单年贡献 20.3%、样本外 −11.9% → 直接判 regime 依赖。

## 9. 常见错误清单

- [ ] 用 Pearson 而不是 Spearman
- [ ] 混池算 IC（没按池分组）
- [ ] 只报 naive t，不报 NW t
- [ ] 不报 N_eff，让读者以为样本很大
- [ ] 用 iid 自举（区间假性收窄）
- [ ] 分层只报均值不报中位数
- [ ] 分层不控制市场状态 → 辛普森悖论
- [ ] 不做覆盖率检查 → 因子其实只在一小撮票上有效
- [ ] 只看全样本 IC，不看逐年
- [ ] 不做相关矩阵 → 引入马甲因子
- [ ] **把 IC 好当成"能赚钱"**（最大的错误，见门 4 / 门 5）
