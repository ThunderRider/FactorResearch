# 假设：把 vol_20d 作为**正因子**放进 V8 打分

> 状态：门 1（本文写于跑之前，之后不改）· run_id：`20261123-vol20-in-score`
> 前置证据：
> * `research/2026-11_min_pool_breadth/conclusion.md` §8：V8 打分 rank 1-4 是最差的一档，
>   调 clip / 换秩 / 换单因子都救不回来；
> * `research/2026-11_vol_screen_v8/conclusion.md`：**"高波动拖累"被证伪** ——
>   基线 top-4 里高波动成员 +34.78bp/日（甚至高于池均 +26.78），
>   低波动成员 −11.10bp/日。方向与直觉相反。

---

## 1. 经济逻辑

V8 的三因子是"缩量（vol_ratio）+ 冷门（amihud）+ 超跌（ret_20d）"，**没有任何波动率项**。
上一轮诊断显示：同样满足这三条的票，**波动率高的一批在放量日反弹更猛，波动率低的一批继续阴跌**。

区别在哪：

| 画像 | 含义 | 次日行为 |
|---|---|---|
| 缩量 + 冷门 + 超跌 + **低波动** | 没人交易、也没人恐慌 —— **阴跌股** | 继续阴跌，无催化 |
| 缩量 + 冷门 + 超跌 + **高波动** | 刚刚被恐慌抛售 —— **有反弹动能** | 在放量日（高档日）早盘反弹更猛 |

V8 的收益**全部**来自 9:30→11:15 的早盘段（前面已多次测得：小盘池隔夜 −7bp、早盘 +11bp）。
反弹动能恰好在这个时段释放。所以给打分加一个 `+z(vol_20d)`，等于在同一条"冷门超跌"主线里，
**把"阴跌股"换成"刚被砸过的票"**。

**这不是加一个独立 alpha 来源，而是修正三因子缺失的一个维度。**
它天然是**高 beta** 的改动：只在放量高档日有效，这也正好符合 V8"一年只做 160 天"的结构。

## 2. 精确构造

```
池：mac = 000300 ∪ 399905；min = 000852 ∪ 932000（RQData 逐日 PIT）
可交易：|14:30 涨幅| < 9.5% & v1430 > 0 & amt20(T−1) > 5000 万
打分：
  v1（基线）score = −z(vol_ratio) + z(amihud[T−1]) − z(ret_20d)
  v2（本项）score = −z(vol_ratio) + z(amihud[T−1]) − z(ret_20d) + w · z(vol_20d[T−1])
  池内 z，截尾 ±3；vol_20d 用 T−1（与 amihud 同口径）
  主口径 w = 1.0（与另外三项等权，不做权重搜索）；w ∈ {0.25, 0.5} 仅作稳健性披露
选股：mac top 2 + min top N（N=4 为主，50 为稳健性）
权重：0.96 × 档位 / (2+N)；档位 = 399303 72 根斜率 > 0（取前一日），1.0 / 0.01
成本：单边 0.1% × (今日敞口 + 昨日敞口)
收益：1115 为主，0930 / 1330 并列
```

## 3. 可证伪的预测

如果机制是"低波动阴跌股拖累、高波动反弹票贡献"，必须同时看到：

1. **成分替换是定向的**：v2 相对 v1 换掉的票，其 `vol_20d` 应显著更高，且被换掉的那批
   1115 收益应显著更低（否则只是随机换手）；
2. **组合的平均 vol_20d 上升**；
3. **改善集中在高档日**，非高档日变差是允许的（低档敞口只有 1%）；
4. **不是单纯换 beta**：把 v1 缩放到与 v2 同波动后，v2 仍应更优。

如果 v2 只是"买了更高波动的票"而没有选股增益，第 4 条会否掉它。

## 4. 失败判据（**跑之前写死**）

切分 `split = 2024-12-31`，禁运 120 交易日，OOS 从 2025-07-03 起（与前两轮一致）。
判决对象：**min 腿单位敞口日收益**（高档日，1115，bp/日）。

| 编号 | 判据 | 违反后果 |
|---|---|---|
| **V1** | OOS 内 `v2 N=4 ≥ v1 N=4 + 2bp/日` | 假设不成立 |
| **V2** | IS 内 `v2 N=4 > v1 N=4`（同向） | 不成立 |
| **V3** | OOS 内 `v2 N=50 ≥ v1 N=50`（宽口径不得变差） | 只在窄口径有效 → 不可用 |
| **V4** | `v2 N=4` 剔除最好 5 个高档日后仍 > 0 | 单日驱动 |
| **V5** | 同波动缩放后 `v2 N=4` 仍优于 `v1 N=4` | 只是换 beta |
| **V6** | 加权 w=0.25 / 0.5 / 1.0 三个值里，**至少两个**在 OOS 上优于 v1 | 只在一个权重上成立 → 过拟合 |

**V1–V6 任一失败 → 最高 `candidate`；全过才允许进 `active` 讨论。**
（注意：即便全过，OOS 只有 44 个高档日，也只能算"值得继续观察"。）

## 5. 已知问题（必须先承认）

1. **`vol_20d` 在 registry 里的身份是 `control`**，不是选股因子。把它放进打分会改变
   组合的风险画像（更高 beta），对外表述必须写清楚"这是 beta 择时 + 选股的混合改动"，
   不能包装成"新增一个 alpha 因子"。
2. **这是对一个样本内观测的再检验**（"低波动成员更差"是我在同一份数据里看到的），
   所以只能用 OOS 做判决。
3. w 是一个自由参数；虽然主口径先验取 1.0，但 V6 已经把它纳入判据。
4. 与 `amihud` 可能高度共线（amihud ≈ |收益|/成交额，与波动同源），
   加进去可能只是把 amihud 的权重放大。必须报 `z(vol_20d)` 与 `z(amihud)` 的截面相关。
5. 本研究改的是打分构造，不新增 `factors.yaml` 条目；但如果判决为 candidate，
   `vol_20d` 的 `status` 需要从 `control` 改为 `control + selection`（门 7 动作）。
