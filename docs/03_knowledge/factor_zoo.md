## 0. 读表须知

**样本与口径**（旧项目 wpqc 的统一样本，所有 IC 都在此口径下）：

```
区间：2023-09-11 ~ 2026-10-28（755 个交易日，部分因子有效样本更短）
池：  mac（沪深300+中证500） / min（中证1000+中证2000）
标签：ret_total = 14:45 买入 → 次日 11:15 卖出（30 分钟 bar 中点近似）
IC：  池内 Spearman RankIC，日频，min_names_per_day = 30
t：   NW(20) = Newey-West 滞后 20 阶；naive t 会高估 20–30%
```

**⚠️ 这张表的局限**（必须知道）：

1. **样本只有 3.2 年**，且含一个极端 regime（2024 初小盘流动性危机）+ 一个衰减期（2026）。
   块自举给出 V3 年化 95% CI = `[−7.3%, +28.9%]` —— **和 0 还没分开**。
2. **没有市值表参与正交化**（旧项目工作区缺估值数据，用 20 日均成交额做规模代理）。
   这对 `amihud` 的"非流动性溢价"叙事是硬伤，详见 [L3](lessons_learned.md#l3--三个因子可能只是两个因子)。
3. **单只股票的 IC 集中在小盘池**。大盘池大多数因子 IC 减半（表里分行给出）。

## 1. 量价类

### `vol_ratio` · 同时刻量比 ⭐ 唯一通过全部检验的因子

| 项 | 值 |
|---|---|
| **定义** | `v1430 / rolling_mean(v1430, 20, min_periods=10)` |
| 含义 | `v1430` = 14:00–14:30 那根 bar 的成交量；分母是**同一时点**的 20 日均量 |
| 方向 | **越小越好**（缩量 = 冷门 = 次日更易被重新发现） |
| 小盘池 IC | **−0.048**（NW t **−11.4**，N_eff 424，块自举 CI `[−0.056, −0.040]`） |
| 大盘池 IC | −0.017（NW t −4.35，N_eff 782） |
| 分层 q10−q1 | **−38.5bp/日**（三因子中最强） |
| 逐年 | −0.052 / −0.056 / −0.048 / −0.036（**四年同向**） |
| 正交化 | 对 `log 成交额 + vol_20d` 正交后 IC **保留 96%**，净年化只掉 0.55pp |
| 置换重要性 | ΔSharpe 0.348（含噪声对照 0.669 ⚠️ 低于对照 → 单因子贡献存疑） |
| **状态** | **`active`** |

**为什么它是最结实的**：它是三因子里**唯一在对流动性/波动正交后仍保留 96% IC 的因子**。
也是唯一能在"IC 好但不独立"的筛选中活下来的。

**已知缺陷**：
- 只用**一根** bar 的量。理论上可换 13:30–14:00 或累计量，但那属于参数搜索（记账里没有，做了要计 N）。
- 停牌复牌首日必然放量，靠 `v1430 > 0` 与流动性门槛部分过滤。
- 置换重要性只有 0.348，**低于"噪声占一槽"的 0.669** —— 这个矛盾说明：
  "缩量信号"在有 `amihud` 同时存在时，边际贡献被后者吸收。

**待做**：① 换 bar 的敏感性（13:30/14:00/累计）；② `min_periods=10` 敏感性；③ 真市值正交。

### `amihud_lag` · 非流动性（冷门）

| 项 | 值 |
|---|---|
| **定义** | `amihud = rolling_mean(\|daily_ret\| / day_amt, 20, min_periods=10)`；**再 `.shift(1)`** |
| 方向 | **越大越好**（越不流动/越冷门） |
| 小盘池 IC | **+0.033**（NW t **+5.5**，N_eff 617，CI `[+0.019, +0.042]`） |
| 大盘池 IC | +0.0076（NW t +1.46 → **不显著**） |
| 置换重要性 | **ΔSharpe 0.981**（最强，但对照 0.669 → 净信息约 0.31） |
| **独立性** | ❌ **对控制变量正交后 IC 符号翻转** |
| **状态** | **`active`（但必须改写叙事：不是"非流动性溢价"）** |

**为什么不独立**（关键表）：

| 变体 | 日均 IC | 净年化 | 相对原始 |
|---|---|---|---|
| 原始 | +0.0103 | 9.59% | — |
| ⟂ `log 成交额` | **−0.0315**（符号翻转） | 5.38% | −4.21pp |
| ⟂ `log 额 + vol_20d + ret_20d` | −0.0048 | **0.52%** | **−9.07pp** |
| ⟂ `行业 + log 额` | −0.0254 | 2.28% | −7.31pp |

**结论**：它的预测力几乎完全是"**低流动性 + 高波动 + 超跌**"的合成包装，
**不存在独立的 Amihud (2002) 非流动性溢价**。

**必须这么说**：> "流动性/波动/超跌综合暴露"，**不是**"多维打分"、**不是**"非流动性溢价"。

**待做**：对**真市值**正交（旧项目用成交额代理，这是最可能被尽调击穿的一条）。

### `ret_20d` · 20 日反转

| 项 | 值 |
|---|---|
| **定义** | `c1430 / c1430.shift(20) − 1` |
| 方向 | **越小越好**（超跌） |
| 小盘池 IC | **−0.052**（NW t **−6.8**，N_eff 518，CI `[−0.067, −0.038]`） |
| 分层 q10−q1 | 次于 `vol_ratio` |
| **逐年** | −0.049 / −0.051 / −0.072 / **−0.029**（⚠️ 2026 年**腰斩**） |
| 重合 | `× ret_5d = 0.43`、`× vol_ratio = 0.34` |
| 置换重要性 | ΔSharpe 0.609（对照 0.669 → ⚠️ **低于对照**） |
| **状态** | **`watch`**，已触发退役评估 |

**为什么降级**：2026 年 IC 从 −0.052 掉到 −0.029，**过半衰减**。
这不是过拟合，是《防过拟合系列》第二篇讲的**非平稳性**。

**退役规则（已写入 registry）**：

```yaml
retire_if:
  - 连续 2 个季度 IC 绝对值 < 全样本一半（即 < 0.026）
  - 正交后 IC 保留率 < 40%
```

**注意**：现在**不要动它**。动了就是又一次样本内优化。
正确做法是设规则、等触发。

## 2. 波动 / 结构类

### `resi` · 去趋势残差波动（旧 V1 线的主力）

| 项 | 值 |
|---|---|
| **定义** | `ln(典型价)` = `ln((high+low+close)/3)`；对 40 根 30 分钟 bar 做线性回归，取**残差的标准差** |
| 方向 | 原假设"越小越稳"；实测 IC −0.058（看起来最强） |
| **致命问题** | 与 20 日波动率相关 **0.72** —— **它就是"买高波动"的马甲** |
| 小盘池选股超额 | −0.033%/日（t = **−0.64**，不显著） |
| 组合层 | V1 毛年化 21.5%、净 **+0.9%**、MDD −38.7%、前 10 天贡献 **97%** |
| **状态** | `rejected`（作为主因子）；`watch`（作为对照） |

**必做的等价性测试**：把 `resi` 换成纯 `vol_20d` 重跑 V1，看选股差多少。
如果等价，V1 的"去趋势波动"故事就该改写成"买高波动"。

## 3. 日内结构类

这批因子都基于 30 分钟 bar 的**日内快照**（截至 14:30），因此天然 PIT 安全。

| 因子 | 定义 | 备注 | 状态 |
|---|---|---|---|
| `late_mom` | `c1430 / c1400 − 1`（最后一根 bar 的动量） | 预期被 FDR 筛掉 | `watch` |
| `late_mom_2b` | `c1430 / c1330 − 1`（两根合成） | 变体，未单独记账 | `draft` |
| `close_pos` | `(c1430 − day_low) / (day_high − day_low)` | 预期被 FDR 筛掉 | `watch` |
| `intraday` | `c1430 / o1000 − 1`（日内涨幅） | ⚠️ 与 `gap` 合成 `day_ret` 时注意 | `watch` |
| `gap` | `o1000 / c1500.shift(1) − 1` | **涨停污染源**，见下 | **`rejected`** |
| `updown_5d` | `log((5 日放量上涨量之和 + 1) / (5 日放量下跌量之和 + 1))` | 量能方向性 | `draft` |

### `gap` 为什么被删（重要教训）

```
加可交易过滤后，单独用 gap 排序：年化 −81.5%
不加可交易过滤时：+14,807%（幻觉）
```

**原因**：`gap` 的极端值全是**涨停/跌停跳空**。这类"跳空"在现实中无法按收盘价成交，
不加过滤时会挑出一堆不可交易的票，回测变成"买在涨停板上"。

**结论**：`gap` 保留为**可交易过滤的输入**（`|day_ret| < 9.5%`），**不作为打分项**。

## 4. 择时 / 仓位层（不是选股因子）

### `tier` · 指数成交量斜率档位

| 项 | 值 |
|---|---|
| **定义** | 指数（大盘池用 `000300.XSHG`，小盘池用 `399303.XSHE`）30 分钟成交量的线性回归斜率；`> 0` → 档位 1.0，否则 → 1/16 |
| 窗口 | 大盘 **102 根 bar**（≈13 天）；小盘 **72 根 bar**（≈9 天） |
| 作用 | **只决定"投多少"，不决定"买什么"** |
| 安慰剂 | **第 98.8 分位**（Sharpe 第 97.6 分位）→ **通过**；安慰剂中位 −3.05% |
| 分年贡献 | 2023 −2.44pp / 2024 **+27.16pp** / 2025 −7.35pp / **2026 +33.73pp** |
| **状态** | **`active`** —— 全套里唯一通过安慰剂的层 |

**2026 年的决定性数字**：带档位 **+0.77%**，满档 **−32.96%**。

**注意**：这是"避险型"信号，价值在**极端时少亏**，不在"平时多赚"。
见 [L17](lessons_learned.md#l17--避险型信号的价值不在平时多赚而在极端时少亏)。

**唯一没留记录的参数**：`slope_window = 102 / 72`。敏感性未做（P2-12）。
判定标准参考旧项目自己用过的：符号一致率 **> 85%**（mac 89.5% / min 77.4%，那次 23% 翻转直接把收益打负）。

### `disp` · 离散度决策器（在哪条选股线之间切换）

| 项 | 值 |
|---|---|
| **定义** | `disp = 全池当日 ret_5d 的截面 IQR(Q75−Q25)`；`pct = disp 的 120 日扩展分位`；`use_v1 = pct < 0.5` |
| 假设 | 分化低 → 用"高弹性"线（V1）；分化高 → 用"错杀修复"线（V3） |
| 胜率 | 204 次触发 / 755 天 = **27.0%** |
| 触发质量 | 均值 +6.00bp，**中位数 −0.21bp**（多数小亏 + 偶尔大赢） |
| 24 格稳健性 | 全样本 10/24 胜过 V3，样本外 **7/24** |
| 安慰剂 | 全样本 **87.8 分位（不显著）**；OOS 99.1 分位但**禁运后不成立** |
| **PBO** | **56.3%**（等于抛硬币） |
| 2026 归因 | 全年 +0.85pp 超额，**全部来自 2026-03-24 一天**（+4.51pp）；剔除后 **−3.50pp** |
| **状态** | **`rejected`**（实盘默认关闭）；`watch`（研究记录） |

**两条"反优化"加分项**：
1. 全样本 SR 最高的是 `T=0.6`（0.97），文档选了中性 `T=0.5`（0.91）—— **主动放弃最优点**。
2. 参数在两年间从 `W120` 漂到 `W250` —— **承认它不稳定**，而不是继续调。

## 5. 其他项目的因子

### `ASP_slope` · 成交额斜率（hzbplus）

| 项 | 值 |
|---|---|
| **定义** | `slope = LINEARREG_SLOPE(total_turnover, N)`，N ∈ [5, 120] |
| 信号 | `slope` 由负转非负 → 买；由正转负 → 卖 |
| 执行 | `signal_lag = 1`（次日开盘/收盘执行），避免未来函数 |
| 单股回测 | 每只股票独立寻优 `LONGPERIOD`，取 `total_return` 最大者 |
| **状态** | `draft`（**没有做过截面 IC / 组合层 / 审计**；单股参数寻优属于样本内最优） |

**已知问题**：① 单股参数寻优 = 每只股票一次搜索，N 极大；② 未做涨跌停/停牌约束；
③ 只在"单股择时"层面验证，没有组合层证据。

**要进 `active`，必须补**：截面化（同一天横截面比较斜率）→ IC / 分层 → 组合层 → 审计。

### `CLS_score` · 财联社电报热度（hfc / wpqc.cls_pool）

| 项 | 值 |
|---|---|
| **定义** | 时间衰减加权提及次数 `Σ 0.5^(age/半衰期)`，`age` 以交易日计，半衰期 5 |
| 池 | 356 个交易日里的每日票池，日均 155 只（含历史累积）；仅当日新增 ≈35 只 |
| PIT | **已通过 4 项检验**，含"截断不变性"8/8 —— **这是全项目 PIT 做得最干净的数据** |
| **已知问题** | 原文档明说："`score` 只是**排序便利**，未做任何有效性验证" |
| **状态** | `draft`（作为**池构造**是合格的；作为**因子**未验证） |

**最关键的负面结果**（`EVAL_V8_ON_CLS.md`）：

> V8 的选股边际集中在因子横截面最极端的 **0.1% 尾部**（99.9~100% 分位 +13.3bp/次，其余 −2.2bp）；
> 而 CLS 票池被**结构性挡在尾部之外**（选中个股平均分位 **0.76~0.82**，全市场 0.999），
> 因为"有电报"≈"已被关注"，与 V8 要的"冷、低流动性、深度超跌"**在同一根轴上反向**。
> 323 天全天候口径：V8 原生选股价差 **+50.98%/yr（t=3.46）**，套到 CLS 上只有 **+2.35%（t=0.24）**，
> 配对自举 P(无差)=0.008。

**这是"因子有效 ≠ 因子可迁移"的教科书案例。** 值得单独成条：

### L24 · 有效因子的边际往往在尾部，而事件类票池结构性地排除尾部

**现象**：某个因子在横截面上有效，但把它套到一个"筛选过的池"上，效果归零。

**数字**：V8 原生 +50.98%/yr（t=3.46）→ 套到 CLS 池 +2.35%（t=0.24），配对自举 P(无差)=0.008。

**结论**：**不要问"这个因子在别的池上还有效吗"，要问"这个池在因子的排序轴上处于哪个位置"。**
CLS 票池的平均分位 0.76~0.82，而因子要的是 0.999 —— **不是"效果变弱"，是"结构上够不着"**。

**落地**：`conclusion.md` 必须有"适用池"一节，写明因子在排序轴上的有效区间，
以及新池的平均分位。任何"换个池试试"的想法，先算平均分位。

## 状态定义

| 状态 | 含义 | 允许的说法 |
|---|---|---|
| `active` | 通过 7 道门，可进策略 | "有独立信息，组合层贡献 X pp" |
| `watch` | 部分通过，证据不足 | "样本内有效但样本外未验证，**不得计入业绩预期**" |
| `candidate` | 已登记、正在跑 | "研究中" |
| `draft` | 有定义但未做正式评估 | "未验证" |
| `input` | 不作为因子，只作为构造材料 | — |
| `control` | 只作为正交化的控制变量 | — |
| `rejected` | 任一门实质不通过 | "已证伪，不要再试" + 死因 |
| `retired` | 曾 active，已触发退役规则 | "已退役（原因/日期）" |

## 怎么加一个新因子

1. 查本表 —— 已存在？状态是什么？
2. 在 [`registry/factors.yaml`](../../registry/factors.yaml) 加一条 `status: draft`
3. 在 [`registry/trials_log.csv`](../../registry/trials_log.csv) 开账
4. 按 [`research/_template/`](../../research/_template/) 走 7 道门
5. 判决后回来更新本表与 registry
