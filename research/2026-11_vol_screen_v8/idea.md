# 假设：用高波动排除逻辑修 V8 顶端失效

> 状态：门 1（本文写于跑之前，之后不改）· run_id：`20261123-vol-screen-v8`
> 前置证据：
> * `research/2026-11_min_pool_breadth/conclusion.md` §8：V8 打分的**第一名那一档（rank 1-4）就是最差的一档**，
>   调 clip / 换秩 / 换单因子都救不回来；
> * `artifacts/results/20261123-resi-min-retest/`：库里 `resi` 与 `vol_20d` 在**筛选层面等价**，
>   剔除高波动档能把 V8 top-4 从 −12.08bp 提到 +2.85bp（但那是全交易日口径、且 X 是自由参数）。

---

## 1. 经济逻辑

上一轮已经排除掉"打分构造错误"这个解释：不管怎么算分，最顶端那一撮都亏。
所以问题在**这一撮票本身**。它们的共同画像是"最缩量 + 最超跌 + 最低流动性"，
而这三者在小盘池里同时指向另一件事：**实现波动率最高的一档**。

高波动票为什么在 14:45 买、次日 11:15 卖这段上系统性更差？

* 高波动 = 分歧大 = 隔夜信息释放更剧烈。V8 的收益全部在 9:30→11:15 的早盘段，
  而高波动票在隔夜段的负漂移最深（本轮前面已多次测得：小盘池隔夜 −7bp、早盘 +11bp）；
* 高波动小票在 14:45 这个时点**买不到好价格**（尾盘流动性最差、点差最大），
  回测用中点近似，实盘会更差；
* 涨跌停/停牌/退市整理都集中在高波动档，属于不可交易风险。

**假设**：在选股**之前**剔除当日池内 `vol_20d` 最高的三分之一，把 V8 的 4 只票
从"波动率最高的那一撮"里挪出来，就能修掉顶端失效。

**为什么是"三分之一"而不是搜出来的百分位**：这是先验的、不做参数搜索的分界；
本轮**只测这一个阈值**，其它阈值只作稳健性披露、不作为判决依据。

---

## 2. 精确构造

```
池：mac = 000300 ∪ 399905；min = 000852 ∪ 932000（RQData 逐日 PIT 成分）
可交易：|14:30 涨幅| < 9.5% & v1430 > 0 & amt20(T−1) > 5000 万
波动过滤：vol_20d(T−1) 在**当日池内**的分位 > 2/3  →  剔除
打分：score = −z(vol_ratio) + z(amihud[T−1]) − z(ret_20d)，池内 z，截尾 ±3
选股：mac top 2 + min top N（N=4 为主，20/50 为稳健性）
权重：0.96 × 档位 / (2+N)；档位 = 399303 72 根斜率 > 0（取前一日），1.0 / 0.01
成本：单边 0.1% × (今日敞口 + 昨日敞口)
收益：1115 为主，0930 / 1330 并列
```

**波动过滤作用在两条腿上**（同一规则，池内计算）。

---

## 3. 可证伪的预测

如果是"高波动票拖累"这个机制，必须同时看到：

1. **被剔除的票确实更差**：基线 top-4 里，被波动过滤剔掉的那些票，
   平均 1115 收益应显著低于同批里保留下来的；
2. **命中率不是 100%**：应该只有一部分 top-4 落在高波动档（否则说明打分本身就在选高波动，
   那是另一个问题）；
3. **改善在宽口径（N=50）上会变小**：宽度已经把高波动票稀释了，过滤的边际作用应该递减；
4. **不是单纯降波动**：把基线缩放到与筛选后相同的波动率，筛选后仍应更优。

如果相反 —— 被剔除的票并不更差 —— 那么"高波动拖累"就是错的。

## 4. 失败判据（**跑之前写死**）

切分 `split = 2024-12-31`，禁运 120 交易日，OOS 从 2025-07-03 起（与前一轮一致）。
判决对象：**min 腿单位敞口日收益**（高档日，1115，bp/日）。

| 编号 | 判据 | 违反后果 |
|---|---|---|
| **S1** | OOS 内 `筛选后 N=4 ≥ 基线 N=4 + 2bp/日` | 假设不成立 |
| **S2** | IS 内 `筛选后 N=4 > 基线 N=4`（同向） | 不成立 |
| **S3** | OOS 内 `筛选后 N=50 ≥ 基线 N=50`（宽口径不得变差） | 只在小窄口径有效 → 不可用 |
| **S4** | 筛选后 N=4 剔除最好 5 个高档日后仍 > 0 | 单日驱动 |
| **S5** | 同波动缩放后，筛选后 N=4 仍优于缩放后的基线 | 只是降风险 |

**S1–S5 任一失败 → `watch`，不得 `candidate`。**

## 5. 已知问题（必须先承认）

1. 本轮测的是**同一份数据上的一个已知方向**，OOS 只有 44 个高档日，功效很低；
2. 阈值 2/3 是先验的，但我已经看过"剔除 10/20/30% 单调改善"这个结果，
   存在**选择性**；因此判决只认 S1–S5，不看全样本的漂亮数字；
3. 波动过滤会**减少候选数**，在某些日子 top-N 可能取不满——必须报"取满率"；
4. 本研究是**构造**问题，不是新因子，`factors.yaml` 不新增条目。
