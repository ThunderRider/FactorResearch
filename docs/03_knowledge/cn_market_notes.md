## 1. 日内成交量的 U 型季节性

**事实**：A 股成交量有强烈的 U 型日内季节性 —— 开盘、收盘放量，中午缩量。

**对因子设计的影响（重要）**：

```
❌ 用「今日全天量 / 过去 20 日全天量」做量比
   → 季节性污染信号：开盘那根的"全天占比"和收盘那根完全不同

✅ 用「同一时点」的 20 日均量做分母
   v_ratio = v1430 / rolling_mean(v1430, 20)
   → 季节性天然消掉
```

旧项目的 `vol_ratio` 就是这么定义的（`notion_docs/02_factors.md` §2.2：
"用**同一时点**的 20 日均量做分母，天然把季节性消掉"）。

**推论**：任何"当日截至某时点"的累计量因子（如 `v_upto_1430 / v_ma20_upto_1430`），
分母也必须是**同一时点口径**，不能用全天均量。

## 2. 午后开盘（13:00–13:30）有一波放量

**实测**（持仓股次日 30 分钟成交额中位数，单位万元）：

| 时段 | 中位 | 25 分位 | 10 分位 |
|---|---|---|---|
| 11:00–11:30 | 517 | 282 | 170 |
| **13:00–13:30** | **649** | **355** | **216** |
| 14:30–15:00 | 921 | 534 | 360 |

**13:00–13:30 比 11:00–11:30 高 22%。**

**这意味着**："午盘清淡"的经验在 13:00–13:30 **不成立**。
用平方根冲击模型算，延后卖出反而**少付 3~7bp** 冲击成本。

**但**：真正的约束是**总容量**，不是时点。按 5% 参与率、单点出货，
AUM 上限约 600 万（33% 敞口）。要支撑更大规模，必须拆批（13:00–14:30 分 3–4 批）。

**来源**：`EXPERIMENTS_V1_V6.md` §12.6。

## 3. 涨跌停导致的截断分布

**事实**：涨跌停把收益分布截断，产生两个后果：

### 3.1 极端值不是"信息"，是"不可交易"

旧项目的实证：

```
gap 因子（隔夜跳空）：
  不加可交易过滤 → 年化 +14,807%    ← 幻觉：买在涨停板上
  加可交易过滤   → 年化 −81.5%      ← 真实：跳空本身没有预测力
```

**规则**：`|当日涨幅| >= 9.5%` 的标的当日**不纳入选择**（无法按收盘价成交）。
这在 `configs/default.yaml` 里是 `market.limit_tolerance: 0.095`。

### 3.2 用 Pearson 会被截断分布绑架

涨跌停让分布有厚尾 + 上截断，Pearson 相关被个别大票主导。
**所以因子评估一律用 Spearman RankIC**（见 `factor_eval.md` §2）。

### 3.3 各板块的涨跌停幅度不同

| 板块 | 代码 | 涨跌停 |
|---|---|---|
| 主板 | 600/601/603/605, 000/001/002/003 | ±10% |
| 创业板 | 300/301 | ±20% |
| 科创板 | 688/689 | ±20% |
| 北交所 | 8xx / 4xx | ±30% |

**ST 股票的幅度是 5%** —— 所以"剔除 ST"不只是风控，也是为了让涨跌停阈值统一。

**推论**：如果策略只做主板，用 9.5% 统一阈值是安全的；
如果包含创业板/科创板，9.5% 会**误伤大量正常交易日**（20% 板里 10% 只是半个板）。

## 4. 停牌与缺失

### 4.1 停牌日的正确处理

| 做法 | 后果 |
|---|---|
| ❌ 从面板里删掉 | 该票"消失"，选股时不会选到它，但**统计上等于它不存在** → 幸存者偏差 |
| ❌ 保留但收益填 0 | 等于"按 0% 成交" → **回测被高估**（停牌通常伴随坏消息） |
| ✅ 保留在索引里（值为 NaN）+ 显式记账 `n_miss` + 回测时按"下一个可交易日"顺延 | 唯一诚实的做法 |

旧项目实测：选股层面 6048 行里有 8 行缺失（0.132%），全在样本最后一天。
影响 0.00pp —— **量级小，但必须记账，不能依赖 pandas 的 skipna 语义。**

### 4.2 `shift(1)` 的语义陷阱

```python
# 如果停牌日被删掉，shift(1) 是「上一个有数据的日子」，不是「昨天」
df.groupby('ticker')['close'].pct_change()   # 停牌后复牌那天 = 跨多日的收益

# 停牌日保留在索引里（NaN），shift 的语义才与日历一致
```

**这就是 `data_layer.md` 要求"停牌日保留在索引里、值为 NaN"的原因。**

## 5. 股票池的 PIT 问题（最容易翻车的一处）

### 5.1 指数成分股会变

```python
❌ codes = rqdatac.index_components('000300.XSHG')             # 今天的成分
✅ codes = rqdatac.index_components('000300.XSHG', date=d)     # 当日的成分
```

**后果**：用最新成分回测历史 = 只测"活到今天的赢家" = **系统性高估**。

旧项目为此专门构建了每日快照：`cn_mac_pit_universe_*.parquet`（长表，每日一行一票）。

### 5.2 上市未满 N 日

次新股波动异常（无历史量基准、无套牢盘、常有连续涨停）。
统一门槛：`min_listing_days: 365`（见 `configs/universe.yaml`）。

**注意**：这是"当时上市满 365 天"，不是"现在满 365 天"。

### 5.3 ST 状态是每日变化的

必须用**当日**的 ST 标记（`cn_st_stock_days`），不能用最新快照。

### 5.4 北京交易所（BSE）

流动性结构特殊（做市商制度、涨跌停 30%），**默认排除**。
如果要包含，必须单独做涨跌停阈值与流动性门槛。

## 6. 复权

### 6.1 后复权是回测的正确选择

| 类型 | 收益率正确 | 绝对价格有意义 | 用于 |
|---|---|---|---|
| 不复权 | ❌ 分红送股会制造假跌 | ✅ | 只看"当时的股价"场景 |
| 前复权 | ✅ | ✅（但是"今天的价格坐标系"） | 当前交易的图表 |
| **后复权** | ✅ | ❌（数值无经济意义） | **回测、因子计算** |

**规则**：`data/curated/` 一律后复权。

### 6.2 后复权的隐藏问题

后复权序列在**每次分红送股后整体变化**。所以：

- ✅ 算收益率安全
- ❌ 判断"股价 < 5 元"不安全（不是真实股价）
- ❌ 用"价格水平"做因子（如"低价股效应"）不安全

**修法**：需要价格水平时，用**不复权**价配合**当时的**复权因子。

### 6.3 复权因子本身也有 PIT 问题

严格来说，`as_of` 时点之后的复权因子是不可知的。
实务上接受后复权（因为收益率不变），但**必须在文档里标注**这个假设。

## 7. 交易日历

### 7.1 别用工作日外推

```python
❌ pd.bdate_range(start, end)          # 会把春节、国庆当交易日
✅ rqdatac.get_trading_dates(start, end)
```

旧项目 `cls_pool` 曾用工作日外推补齐了 10 天（"11 月无长假，风险极低"），
但明确写进了"已知局限"——这是可接受的做法，**前提是写清楚**。

### 7.2 长假后的第一个交易日信息量最大

这才是 `lookahead_audit.md` 要求"截断不变性检验必须包含一个长假后交易日"的原因：
信息堆积最多，最容易暴露 PIT 问题。

旧项目 `cls_pool` 的窗口设计专门为此改过：

> CLS 在周末与法定节假日照常发报。若按自然日"昨天 14:30"切窗，
> **周末/假日前最后交易日 14:30 之后到周末之间的电报会掉进没有任何票池认领的空档**。
> 实测漏掉 **123 / 12,918 条提及（1.0%，涉及 114 只股票）**，
> 星期分布 `Fri: 117, Thu: 4, Tue: 2`，**全部发生在 14:30 之后**。
> 改用"上一交易日 14:30"后，每条电报恰好被一个窗口认领（零丢失、零重复）。

**这是"事件类数据 + 交易日历"的经典坑，值得记住。**

## 8. 成本结构

| 项 | 量级 | 说明 |
|---|---|---|
| 佣金 | 万 2.5 ~ 万 3 | 双边收 |
| 印花税 | **千 1（卖出单边）** | 2023-08 后减半至 0.05% |
| 过户费 | 万 0.1 | 双边 |
| 滑点 | 视流动性 | 小盘股可达 20~80bp |

**统一口径**：`单边 0.10%`（佣金 + 印花税折半 + 滑点合计）。
这是 `configs/default.yaml` 的 `costs.one_way: 0.0010`。

**敏感性必须报**：`0.10% / 0.15% / 0.20%` 三档。
旧项目实测：**成本每 +5bp/边，年化掉约 8.3pp。**

> ⚠️ 固定成本假设在规模上不成立。真实冲击用平方根模型
> `impact = 0.5 × σ_daily × √参与率`，小盘股 σ=2.8% 时，
> 参与率 20% 的冲击约 63bp —— **比 0.10% 高 6 倍**。

## 9. 小盘股的 α 与它的代价

**事实**（旧项目实测）：

| 项 | 数字 |
|---|---|
| 持仓平均市值分位 | **0.179**（总在最小 18% 里挑） |
| 大盘池持仓落在最小三分档的比例 | **93.8%** |
| 强制市值分层后 | 收益掉 **4~12pp**，**回撤反而变大** |

**结论**：
1. 这套 alpha **本身就在最小市值段**，剥离不掉；
2. 所以"控市值暴露"只能是**仓位层面**（对冲、中性化），不是选股层面分层；
3. 因此策略的**容量小、风格依赖强**——这是同一个事实的两面。

**2024 年初的小盘股流动性危机**（全市场小盘两周跌 30%+）就是这类策略的固有风险：
V6 的最大回撤 −24.93% 正好发生在那段（2023-11-03 ~ 2024-02-06），**恢复用了 288 天**。

**这不是"策略失效"，是"策略所在的环境崩了"** —— 但产品层面一样要承受。
评价这类策略必须看"最差年份"与"恢复时间"，不能只看平均。

## 10. 隔夜 / 日内收益的分离

A 股的"隔夜段"和"日内段"在统计上几乎是两个市场：

| 段 | 特征 |
|---|---|
| 隔夜（15:00 → 次日 9:30 开盘） | 受外盘、消息、情绪影响；跳空 |
| 日内（9:30 → 15:00） | 受资金流、日内动量影响 |

旧项目把 `ret_total` 拆成三段（`ret_tail` / `ret_overnight` / `ret_morning`），
立刻发现了一个关键事实：

```
V1（高波动票）的隔夜段是 −13.9bp（净拖累）
V3（低波动冷门票）的隔夜段是 +6.7bp（贡献）
```

**"V3 比 V1 好"的真正原因，不是"选得更猛"，而是"隔夜不再亏"。**

**推论**：任何日内到次日的策略，**必须把收益拆成隔夜 + 日内分别看**。
混在一起会看不出"改进来自哪一段"。
