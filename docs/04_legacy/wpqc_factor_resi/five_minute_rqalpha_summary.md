
## 15.3 5m 精细撮合实验结果分析

### 核心结论

把撮合从 30m 近似的 `15:00 -> 次日 11:30` 改成 5m 数据上的 `14:45 -> 次日 11:15`，并把费用改成接近 RQAlpha 的股票费率后，结果相比上一版保守压力测试明显改善，但**仍然没有达到可实盘标准**。

本次 5m + RQAlpha 费率下：

| 指标 | 策略 | 沪深300 |
|---|---:|---:|
| 总收益 | `-57.05%` | `16.41%` |
| 年化收益 | `-12.92%` | `2.52%` |
| Sharpe | `-0.09` | `0.23` |
| 最大回撤 | `-81.68%` | `-45.60%` |
| 超额收益 | `-63.11%` | - |
| 超额最大回撤 | `-78.80%` | - |

所以这次实验的正确解读是：**上一版 `-92.21%` 的结果确实过于悲观，但当前策略在真实交易时间和 RQAlpha 费率下仍然是负收益、负超额、高回撤。**

### 和上一版 30m 回测的对比

- 30m 近似 + 保守成本：策略总收益 `-92.21%`。
- 5m 精确时间 + RQAlpha费率：策略总收益 `-57.05%`。
- 30m 零成本：`358.57%`。
- 5m 零成本：`210.55%`。

这说明两个事实：

1. 成本口径从“保守压力测试”改成 RQAlpha 费率后，净值显著改善。
2. 但 5m 精确到 `14:45/11:15` 后，零成本毛收益反而低于 30m 近似口径，因此不能说真实撮合时间本身改善了信号。

更准确地说：**这个因子组合有毛 alpha，但毛 alpha 对交易时间和成本都很敏感。**

### 成本影响

- 5m 零成本收益：`210.55%`
- 5m RQAlpha费率收益：`-57.05%`
- 成本拖累：约 `267.60%`
- vectorbt 百分比费用合计：约 `1,018,390` 元
- 按 RQAlpha `5元最低佣金` 重新估算的精确费用合计：约 `1,018,390` 元
- 最低佣金触发订单数：`0 / 9110`

最低佣金没有触发，说明这次 vectorbt 百分比费率和 RQAlpha 费用几乎一致。结果不是因为最低佣金估算误差造成的，而是因为每天买入、次日上午卖出的 round-trip 成本累积太重。

### Walk-forward 样本外

- 样本外测试窗：`9` 个
- 正收益测试窗：`4` 个，占比 `44.44%`
- 跑赢沪深300测试窗：`4` 个，占比 `44.44%`
- 平均测试窗收益：`-1.84%`
- 平均测试窗超额：`-2.80%`

最好的一折是 `2024-07-01 ~ 2024-12-31`，收益 `38.42%`，超额 `22.36%`。最差的一折是 `2022-01-01 ~ 2022-06-30`，收益 `-36.16%`，超额 `-30.01%`。

样本外表现比上一版好很多，但仍然没有形成稳定优势：不到一半测试窗为正，也不到一半测试窗跑赢沪深300。

### 年度稳定性

- 年度正收益比例：`28.57%`
- 2024 年收益 `14.42%`，但超额 `-1.53%`
- 2025 年收益 `37.68%`，超额 `13.61%`
- 最差年份是 2023 年，收益 `-35.91%`，超额 `-27.38%`

年度层面只有 2024、2025 为正，且 2024 仍小幅跑输沪深300。策略更像是在 2024H2 到 2025 阶段短暂恢复，而不是全周期稳定有效。

### 交易可实现性

数据和撮合层面是干净的：

- `14:45` 和 `11:15` 5m bar 每个交易日都存在。
- 有效交易日 `1521` 天。
- 平均实际持股数 `2.99` 只。
- 买入价格缺失合计 `0`。
- 卖出价格缺失合计 `0`。
- 平均集合换手率 `34.06%`。

所以当前问题不是“数据没撮合上”，而是策略交易结构本身太吃交易摩擦。

### 最终判断

1. **当前版本仍不建议实盘。** 总收益 `-57.05%`、超额 `-63.11%`、最大回撤 `-81.68%`，风险收益不合格。
2. **信号仍有研究价值。** 5m 零成本仍有 `210.55%` 毛收益，说明高 `RESI` 后低 `rolling_coef_std` 不是完全无效。
3. **问题核心仍是成本和换手。** 每日 round-trip、持仓只有约 3 只、换手约 `34%`，费用累积后把毛收益打穿。
4. **下一步不要优先继续调 window/topN。** 更应该测试降低换手：持仓 2~5 天、只在新票显著优于旧票时换仓、加入换手惩罚、设置最小预期收益阈值。
5. **如果进入更真实回测，应加入涨跌停、停牌、成交量约束和冲击成本。** 当前 5m vectorbt 版本已经比 30m 精确，但还不是完整生产级撮合。

一句话：**5m + RQAlpha费率救回了一部分结果，但还没有救回策略。这个方向可以继续研究因子毛 alpha，但当前交易方式不能上线。**
